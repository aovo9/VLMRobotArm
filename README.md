# Open-Manipulator-VLM

## 하드웨어
- Jetson orin
- Open Manipulator-X
- Realsense d435
- 키보드, 마우스, 모니터, 마이크

## 소프트웨어
- VS Code
- Python
- **로봇제어 :** ROS2 humble / Ubuntu 22.04
- **음성인식 :** whisper
- **이미지 :** YOLO V11
- **손 인식:** mediapipe or YOLO Pose

## 유사 프로젝트
[Open-Manipulator-LLM](https://github.com/Demolus13/Open-Manipulator-LLM)

이 프로그램 참고하여 손 인식 등의 추가 옵션 성공하면
VLM을 활용해 음성과 이미지 인식을 통합

## 과정

- 환경 설정
- 하드웨어 및 각 노드 동작 확인 (omx, whisper 등)
- 학습 데이터 수집 및 학습(잡을 물건, 손 등)
- OMX 움직임 미세 조정
  - 크게 움직일 땐 빠르게(move_group)
  - 물건 놓을 땐 미세하게(servo)
- 메인 노드 만들어 각 단계 통합
  - 소규모 파라미터 llm 이용
- 실패-재시도 매커니즘 구성
- 완성 시 입력-분석 단계를 vlm으로 통합

# 프로젝트 진행 상황

## 1. 유사 프로젝트 동작 정리
- [각 파일별 기능 설명](https://www.notion.so/LLM-OMX-Project-6c2483626a744a5f862b65cb9a10cb19?p=35b7883f6ca8807f8b74f070a14859a5&pm=s)
- **환경 :** ROS1 Noetic
- **색상 기반 탐지 :** OpenCV를 활용해 HSV 범위를 기준으로 특정 색상을 지닌 객체 검출
- **좌표 계산(Calibration) :**
  화면 상의 물체 위치를 로봇이 이해 가능한 3차원 공간 좌표로 변환
- **음성 인식 :** speech_recognition 라이브러리를 사용해 사용자의 목소리를 텍스트로 변환
- **LLM :**
  입력받은 텍스트에서 사용자가 원하는 색상과 동작을 추출
  - Groq API 사용
- **로봇 팔 제어 :**
  OMX End-Effector가 목표 좌표에 도달하도록
  역기구학(Inverse Kinematics) 적용

## 2. 유사 프로젝트 진행

- **환경 구축 :**
  Jetson Orin 환경에서 ROS2 Humble 환경 설정

- **코드 마이그레이션 :**
  기존 ROS1 Noetic 기반 프로젝트를 ROS2 구조로 변경

  - **클라이언트 라이브러리 교체 :** rospy → rclpy
  - **빌드 환경 변경 :** catkin → colcon

     - (ros2_control이 topic [publisher-subscriber] 방식을 사용함)

- **코드 실행 :**
  수정된 Pick_and_place.py 실행

  - 마이크가 없어 텍스트 입력 기반으로 임시 테스트 진행

  - ☑ Realsense를 통한 색상 기반 객체 탐지
  - ☑ 텍스트 입력으로 LLM이 색상과 동작 추출 후 OMX 제어
  - ☑ OMX가 Pick & Place를 정확하게 수행하는가?
  - ☐ 음성을 텍스트로 정확히 변환하는가?

## 4. 프로젝트 단계별 목표 정의 ( 이후 수정할 예정 )

### 📂 Step 1: OMX 블라인드 모션 관통 (1~2주차)
*   **목표**: 카메라 센서 없이 입력한 절대 좌표로 로봇 팔을 부드럽고 안전하게 움직이기.
*   **구현 내용**:
    *   🔹 **수치적 IK 라이브러리 연동**: 초반 수식 유도 지옥을 피하기 위해 `ikpy` 또는 `scipy.optimize`를 활용해 목표 좌표의 관절 각도를 빠르게 추출.
    *   🔹 **S-curve 가속도 제어**: 다이나믹셀 속도/가속도 프로파일을 30% 수준으로 제한하여 관성에 의한 오버슛(Overshoot)을 기계적으로 방지.
    *   🔹 **안전 작동 영역 필터**: 로봇 유효 작업 반경(15cm ~ 25cm) 외의 위험 좌표 진입 시 구동을 원천 거부하는 안전 가드 설치.

### 🔩 Step 2: 물리 오차 흡수 및 전류 피드백 FSM (3주차)
*   **목표**: 하드웨어 기어 유격(Backlash)을 상쇄하고, 로봇에게 물체 파지 여부를 판단하는 감각 심어주기.
*   **구현 내용**:
    *   🔹 **하드웨어 컴플라이언스**: 그리퍼 손가락 안쪽에 3mm 두께의 말랑한 압축 스펀지 패드를 부착하여 수 밀리미터의 제어 오차를 물리적으로 흡수.
    *   🔹 **전류 필터링 및 히스테리시스**: 다이나믹셀 전류 노이즈를 잡기 위해 10개 프레임 이동 평균(Moving Average) 필터 적용. 쥐었을 때의 상한선($Th_{high}$)과 놓쳤을 때의 하한선($Th_{low}$)을 분리해 채터링 없는 파지 판정 상태 머신 구축.
    *   🔹 **결정론적 리트라이 선구축**: 미끄러짐 감지 시 즉시 기존 좌표에서 Z축으로 5mm 낮추거나 Yaw를 15도 틀어 다시 쥐게 만드는 규칙 기반 리트라이 뼈대 선구축.

### 📐 Step 3: 카메라 좌표 변환 및 정적 검증 (4~5주차)
*   **목표**: RealSense의 2D 픽셀 좌표와 깊이(Depth) 데이터를 로봇 기준의 3D 공간 좌표(X, Y, Z)로 정밀 매핑하기.
*   **구현 내용**:
    *   🔹 **정적 TF 트리 고정**: ROS2 환경에서 `base_link`, `camera_link`, `ee_link`, `grasp_link` 프레임 명명 규칙을 고정하고 모든 연산의 종착지를 `base_link`로 통일.
    *   🔹 **센서 노이즈 차단**: RealSense SDK 메디안 필터 및 지수 이동 평균(EMA) 필터를 구현해 지글거리는 깊이 노이즈 제거. 깊이 값이 0인 무효 픽셀은 무조건 거부(Reject).
    *   🔹 **정중앙 픽셀 야매 테스트**: 화면 중앙 픽셀(320, 240) 좌표를 고정해 두고 로봇 팔을 뻗게 만든 뒤, 손끝이 도달한 자리에 손으로 직접 컵을 대보며 캘리브레이션 행렬($T_{cam}^{base}$) 최종 확정.

### 👁️ Step 4: YOLOv11n Detection 자동화 (6주차)
*   **목표**: AI 객체 탐지 기술을 연동하여 사람이 개입하지 않는 최초의 자동 파지 시퀀스 완성.
*   **구현 내용**:
    *   🔹 **순정 PyTorch YOLOv11n**: TensorRT 빌드 지옥을 우회하기 위해 오린 나노 깡스펙을 믿고 생 파이썬 노드로 구동. 탐지된 바운딩 박스 중심점 픽셀을 Step 3의 좌표 변환 코드에 직접 연결.
    *   🔹 **퍼셉션 신뢰도 게이트**: YOLO의 탐지 Score가 0.6 미만일 경우 오인식으로 인한 충돌을 막기 위해 동작을 취소하는 `reject_action()` 가드 설치.
    *   🔹 **소프트웨어 안전 클램프**: 계산된 로봇 좌표가 책상 바닥을 뚫지 않도록 제어 단에서 바닥 높이를 강제 제한하는 안전 보정 코드 삽입.

### 🔄 Step 5: Seg 마스크 및 PCA 경량 파지 각도 (7~8주차)
*   **목표**: 비스듬히 놓인 물체의 기하학적 형태에 맞춰 로봇 손목 관절(Yaw)을 돌려 파지 성공률 극대화.
*   **구현 내용**:
    *   🔹 **Open3D 다운샘플링**: YOLOv11n-seg 마스크 영역의 3D 포인트 클라우드만 슬라이싱한 뒤, 8mm 복셀 필터로 깎아내 연산 속도 확보.
    *   🔹 **PCA 각도 스무딩**: 주성분 분석(PCA)으로 물체 주축 각도를 추출하되, 마스크 깨짐 노이즈 방지를 위해 `0.7 * 직전각도 + 0.3 * 현재각도`로 스무딩하거나 고정 후보 각도(`[0°, 45°, 90°]`)로 이산 양자화.
    *   🔹 **객체별 파지 규칙(Prior) 결합**: PCA가 손잡이나 비대칭 형태에서 쉽게 바보가 되는 현상을 방어하기 위해 "컵이면 상단 20%, 펜이면 정중앙"처럼 클래스별 하드코딩 오프셋 보정 룰 결합.

### 📊 Step 6: 블랙박스 원격 로깅 및 스냅샷 동결 (9주차)
*   **목표**: 로봇 팔이 주행 중 카메라 시야를 가리는 '자기 가림(Self-Occlusion)' 문제를 완벽히 우회하고 디버깅 인프라 구축.
*   **구현 내용**:
    *   🔹 **오픈루프 스냅샷 동결**: 명령이 들어오는 그 순간의 카메라 피드를 **메모리에 프리징(Snapshot)**. 로봇 팔은 이 동결된 좌표만 보고 장님처럼 들어가는 **맹목 제어(Blind Run)** 모드로 작동하여 가림 현상 원천 무력화.
    *   🔹 **텔레메트리 블랙박스 구축**: `snapshot_[UUID]` 폴더를 자동 생성하고 원본 데이터 및 주행 로그를 파일로 덤프하여 완벽한 에러 추적 시스템 완성.
    *   🔹 **STT 키워드 트리거**: Whisper/Vosk 노드를 연결해 "치워" 등의 핵심 키워드 감지 시 위의 스냅샷 트리거 신호를 쏘도록 연동.

### 🧠 Step 7: Local VLM 상주 및 최종 하이브리드 통합 (10~12주차)
*   **목표**: 고차원 추론 능력을 가진 VLM을 최종 탑재하여 모호한 명령 처리 및 실패 회복 시나리오 완성.
*   **구현 내용**:
    *   🔹 **Warm Standby 양자화 VLM**: Qwen2.5-VL(INT4) 모델을 VRAM에 상주시켜 추론 요청만 대기하는 **저전력 Idle 상태**로 유지하여 로딩 지연 시간 제로화. **Grammar Sampling**을 적용해 완벽한 JSON 포맷 출력 강제.
    *   🔹 **시맨틱 태스크 스케줄링**: VLM에게 모호한 명령 해석, 청소 우선순위 조율, 파지 전략 추천을 전담시킴.
    *   🔹 **화이트리스트 검증 FSM**: VLM이 실패 분석 후 리트라이 전략을 제안할 때, FSM 내부 안전 구문 배열(**화이트리스트**) 안에 있을 때만 명령을 패스하고, 환각(Hallucination) 텍스트를 뱉으면 무시 후 Step 2의 디터미니스틱 규칙으로 백업 기동.
